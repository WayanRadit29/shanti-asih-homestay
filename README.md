# Shanti Asih Homestay Website

Shanti Asih Homestay Website merupakan final project pada mata kuliah Pemrograman Web yang bertujuan untuk membangun sistem reservasi homestay berbasis web. Website ini dirancang untuk membantu pengguna dalam melihat informasi homestay, mengeksplorasi kamar yang tersedia, melakukan booking kamar secara online, serta memudahkan admin dalam mengelola data pemesanan dan kamar.

---

## 📌 Deskripsi

Website ini bertujuan untuk membantu calon tamu dalam:

* Melihat informasi homestay
* Mengeksplorasi daftar kamar yang tersedia
* Melihat detail kamar beserta fasilitasnya
* Melakukan registrasi dan login akun
* Melakukan booking kamar secara online
* Melihat riwayat dan status booking
* Mencetak bukti booking dalam format PDF

Selain itu, sistem menyediakan dashboard admin untuk mengelola kamar, booking, dan pengguna secara terpusat.
