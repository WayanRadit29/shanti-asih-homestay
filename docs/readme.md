# GitHub Pages Documentation

Folder `docs` digunakan untuk menyimpan versi awal project **Shanti Asih Homestay** yang dikembangkan sebagai mini project frontend pada tahap awal pengembangan aplikasi.

Folder ini berfungsi sebagai sumber deployment untuk **GitHub Pages**, sehingga website dapat diakses secara online tanpa memerlukan server PHP maupun database MySQL.

## Tujuan Folder Docs

* Menyimpan versi frontend-only project
* Menjadi source deployment GitHub Pages
* Menampilkan prototype awal sistem homestay
* Mendemonstrasikan desain antarmuka dan user flow sebelum implementasi backend

## Teknologi yang Digunakan

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## Fitur yang Tersedia pada Versi GitHub Pages

* Landing Page
* Daftar Kamar
* Detail Kamar
* Pencarian Kamar
* Form Booking (Simulasi)
* Informasi Lokasi
* Responsive Design

## Keterbatasan Versi GitHub Pages

Karena GitHub Pages hanya mendukung website statis, maka versi ini:

* Tidak menggunakan PHP
* Tidak menggunakan MySQL
* Tidak memiliki sistem login
* Tidak memiliki dashboard admin
* Tidak menyimpan data booking secara permanen
* Booking hanya berupa simulasi menggunakan JavaScript

## Versi Final Project

Pengembangan selanjutnya menghasilkan versi full-stack yang menggunakan:

* PHP Native
* MySQL Database
* Session Authentication
* Dashboard User
* Dashboard Admin
* Sistem Booking Real
* Generate PDF menggunakan Dompdf
* Hosting Online menggunakan InfinityFree

Versi final inilah yang digunakan sebagai implementasi utama untuk memenuhi kebutuhan tugas akhir mata kuliah Pemrograman Web.

## Catatan

Folder `docs` dipertahankan untuk kebutuhan dokumentasi dan deployment GitHub Pages, sedangkan implementasi utama aplikasi berada pada root project yang digunakan untuk deployment hosting PHP dan MySQL.
